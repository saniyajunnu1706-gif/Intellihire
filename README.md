## 🎯 About the Project

**Intellihire** is a fully client-side AI-powered technical interview platform built for aspiring AI/ML professionals. It uses **Retrieval-Augmented Generation (RAG)** to serve curated, domain-specific questions and a **Large Language Model (LLM)** to evaluate your answers with precision scoring and actionable feedback.

No generic trivia. No hallucinated feedback. Just real, expert-level interview preparation across 20 AI specializations — all in a single HTML file that runs in any browser.

> *"Intellihire helped me land my ML Engineer role at a top-3 tech company. The feedback was shockingly precise."*
> — Priya M., ML Engineer

## ✨ Features

| Feature | Description |
|---|---|
| 👑 **Royal Welcome Board** | Cinzel-typography landing page with animated gold particles and SVG crown logo |
| 🔐 **Authentication** | Sign up / Login with session persistence via localStorage |
| 🧠 **RAG Question Engine** | 160+ expert questions curated from real AI knowledge bases across 20 tracks |
| 🤖 **LLM Evaluation** | Claude Sonnet 4 scores every answer on Concepts, Depth, Accuracy, and Examples |
| ⏱️ **Timed Sessions** | 2-minute timer per question with red urgency alerts under 30 seconds |
| 📊 **Skill Radar** | Visual breakdown of Concepts / Depth / Accuracy / Examples per session |
| 🔍 **Course Search & Filter** | Search by name, tag, or description — filter by Beginner / Intermediate / Advanced |
| 📈 **Progress Dashboard** | Sessions completed, average score, best score, and question count tracking |
| 📋 **Interview History** | Full session log with scores and grades in a sortable table |
| 🌐 **Internet Guard** | Blocks usage without internet — probes real connectivity |
| 📱 **Responsive Design** | Works on desktop, tablet, and mobile browsers |
| 🎨 **Zero Dependencies** | Single HTML file — no npm, no build step, no server required |

## 🌐 Deployment

### Netlify — Drag & Drop
1. Go to [app.netlify.com](https://app.netlify.com)
2. Put `index.html` in a folder
3. Drag the folder onto the deploy zone
4. Live in 15 seconds ✅

### Netlify — GitHub Auto-deploy
1. Connect this repo to Netlify
2. Leave build command and publish directory empty
3. Every `git push` auto-redeploys ✅

### GitHub Pages
Go to **Settings → Pages → Deploy from branch → main / root**
